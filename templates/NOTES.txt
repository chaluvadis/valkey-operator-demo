To verify the operator is running:

  kubectl get pods -n {{ .Release.Namespace }}

To check cluster status:

  kubectl get valkeycluster -n {{ .Release.Namespace }}
  kubectl get valkeycluster {{ .Values.valkeyCluster.name }} -n {{ .Release.Namespace }} -o jsonpath='{.status.state}' && echo

To view operator logs:

  kubectl logs -f deployment/{{ include "valkey-operator.fullname" . }} -n {{ .Release.Namespace }}

To create an additional ValkeyCluster (beyond the default one):

  cat <<EOF | kubectl apply -f -
  apiVersion: valkey.io/v1alpha1
  kind: ValkeyCluster
  metadata:
    name: my-additional-cluster
    namespace: {{ .Release.Namespace }}
  spec:
    shards: 3
    replicas: 2
  EOF
